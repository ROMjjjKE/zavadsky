# ИП Завадский О. Ю.: сервис и ремонт скважин, Воложин

Пять страниц плюс политика, чистый HTML, CSS и JS. Шапка, подвал и метаданные
собираются скриптом `build.py`, поэтому страницы не разъезжаются.

## Страницы

| Файл | Что внутри |
| --- | --- |
| `index.html` | Главная: разбор симптомов, устройство скважины, работы, выезд, FAQ |
| `uslugi.html` | Шесть направлений: ремонт, автоматика, замена оборудования, прокачка, обустройство, вода и канализация |
| `sistema.html` | Разрез скважины и обвязки, что ломается чаще всего, кессон против адаптера |
| `geo.html` | Воложин и 100 км: Молодечно, Сморгонь, Ошмяны, Островец, Вилейка |
| `kontakty.html` | Телефон, WhatsApp, заявка |
| `politika.html` | Политика обработки данных |

## Интерактив

Разбор симптомов: пять состояний (нет воды, гудит без воды, скачет давление, песок,
вода уходит). Каждое открывает вероятные причины, что проверяем и короткое пояснение.
Сделано без библиотек, состояние кнопок в `aria-pressed`. Блок продублирован на
`sistema.html`, где он читается как «что ломается чаще всего».

Схема скважины нарисована в SVG: обсадная труба, насос, оголовок, труба в дом,
гидроаккумулятор, реле давления. Это поясняющая графика, а не декор: подписи совпадают
с тем, о чём говорится в тексте.

## Что заменить перед запуском

1. **Фотографии.** Снимки в `assets/img/` сгенерированы как временные. Нужны реальные:
   обвязка в доме, кессон, оголовок, работа с насосом. Пропорции: герой 20:24,
   разделы 16:7, блоки 3:2.
2. **Реквизиты.** В политике указан оператор без УНП и адреса.
3. **Домен.** Сейчас `https://romjjjke.github.io/zavadsky/`. Свой домен: Settings → Pages →
   Custom domain плюс `CNAME` и запись у регистратора.
4. **Цены.** В брифе сумм нет, поэтому ни одна цифра не выдумана: вместо прайса
   объяснено, из чего складывается стоимость, и предложена диагностика как первый шаг.

## Проверки

- нет горизонтального скролла на 1440, 1080, 900, 768, 390 и 360 px
- контраст текста от 5.21:1 (кнопка), второстепенный текст 5.62:1
- разбор симптомов проверен: переключение кнопок, панелей и aria-pressed
- форма: пустая не уходит, ошибки показываются, заполненная собирает сообщение в WhatsApp
- меню на мобильном открывается, `hidden` закрыт явным правилом в CSS
